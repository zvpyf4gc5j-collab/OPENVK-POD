# OpenVK Pod

Музыкальный плеер в виде айпода для iOS: треки берутся из твоего аккаунта OpenVK.
Управление только колесом: крути, центр выбирает, MENU назад, по бокам треки, снизу пауза.
На экране «Сейчас играет» центр переключает: перемотка, громкость, перемешивание, повтор.

## Как получить .ipa без Mac
1. Создай репозиторий на GitHub и залей туда всё содержимое этой папки (включая .github).
2. Вкладка Actions: запустится «Build IPA» (или нажми Run workflow).
3. Когда сборка закончится, скачай артефакт OpenVKPod-ipa.
4. Поставь .ipa через AltStore, SideStore или Sideloadly (они подпишут его твоим Apple ID).

## Сборка на Mac
brew install xcodegen, затем xcodegen generate и открой OpenVKPod.xcodeproj.

## Важно
- Вход: в Настройках пункт «OpenVK» (логин и пароль или токен). Токен сохраняется на устройстве.
- Запросы к OpenVK (/token и /method/audio.get) написаны по аналогии с VK API и не проверены.
  Если поля другие, поправь разбор в Sources/OpenVKAPI.swift.
- Код не компилировался на моей стороне: если сборка в Actions упадёт, пришли лог ошибки.
